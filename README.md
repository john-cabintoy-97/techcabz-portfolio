
# Portfolio CMS & Developer Platform

A modern, full-stack developer portfolio and project management platform featuring a complete administrative CMS, built with **Next.js 14 App Router**, **Tailwind CSS**, and **Supabase**.

## ✨ Features

- **Public portfolio** — Clean hero section, about profile, responsive project grid, and project detail pages with Markdown case study rendering.
- **Full CRUD admin CMS** — Securely Create, Read, Update, and Delete projects directly from a protected administrative dashboard.
- **Supabase Authentication** — Secure email/password login flow with SSR-safe session management.
- **Protected route middleware** — Automated middleware checks and redirects unauthenticated users away from restricted `/admin` paths.
- **Server Actions** — Utilizes Next.js Server Actions with automatic `revalidatePath` triggers for seamless mutations.
- **Skeleton loaders** — Performance-optimized loading states (`loading.tsx`) with shimmer skeletons across pages.
- **Dark mode aesthetic** — Sleek violet-accented dark theme tailored for modern developer portfolios.
